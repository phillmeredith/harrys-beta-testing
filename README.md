# Harry's Beta Testing

Tap-first iPad app for Harry to send bug reports and ideas about his Minecraft add-on to Daddy.

- `index.html` is the built app (served by GitHub Pages).
- `src/` holds the parts; run `python3 build.py` from the repo root to rebuild.
- `apps-script/Code.gs` is the Google Apps Script that emails each report to Daddy's Gmail.
